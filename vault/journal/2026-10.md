### 2026-10-11

- **STANDALONE** myelin stands on its own, on the maintainer's call before
  going public. Its spec and the tests built on another program's keymap
  are gone; the code, docs and vault name no private repository, and the
  tests use an invented editor's schema instead. _(Decisions: D8)_
- **GODOC** The package doc is an overview of the whole API; every
  exported identifier is documented; seven runnable Examples, plus one in
  myelintea for a Bubble Tea model. staticcheck reports nothing with every
  check on. _(Decisions: D9)_
- **DOCS** The documentation package, worked out with the Docs Agent:
  README (install, a first keymap), `docs/integrate.md`, `docs/keymaps.md`
  and `docs/design.md`. The code blocks are the Examples, checked for
  drift. _(Decisions: D9)_

  Gate: a green local `make check`.
- **HISTORY** The history starts fresh: one root commit with the reviewed
  tree, and myelintea's myelin pin moved to it. The maintainer ran the
  force-push. _(Decisions: D10)_
- **DOCS-REVIEW** The Docs Agent's review: nothing to fix. The pages
  parse, link and read cleanly in its three modes, and the examples and
  key markers are fine to keep. `docs check` joins the gate when the shared
  module exists.

  Gate: a green local `make check`.
- **TOOLS** msgp's generator moves from the nested `tools/` module into
  `mise.toml`, beside Go, on the maintainer's call; `//go:generate` runs
  `msgp`. CI installs both with mise-action and then tests the root module
  at its go 1.24 floor, which passes locally. _(Decisions: D11)_

  Gate: a green local `make check`.
- **KEY** Keys become the module `github.com/neuroplastio/myelin/key`,
  which requires nothing: the canonical names, ported from hotty-go, with
  the short spelling and sequences. It passes its tests under Go and under
  TinyGo's wasm with 64 KB stacks, and runs HOTTY's `keys` and `keymap`
  vectors from the hotty repository. _(Decisions: D12, D13)_
- **HEADLESS** The root requires `key` instead of hotty-go, and myelintea
  is gone: no UI toolkit's adapter lives in myelin. The guide shows how a
  program names its toolkit's keys. _(Decisions: D13)_

  Gate: a green local `make check`; the root also builds against the
  pushed `key` commit with no replace.
- **MYELINKEY** The keys module is renamed `myelinkey`, module and
  package, since "key" is a bad import name; the root, the docs and the
  guide follow, and `key/` is gone. _(Decisions: D14)_

  Gate: a green local `make check`; the root also builds against the
  pushed `myelinkey` commit with no replace.
- **README** The README is a tour: highlights, why myelin (what it takes
  from VS Code's and Zed's key bindings, with a table), a quick start in
  four steps, config in the styles of Zed's `keymap.json` and VS Code's
  `keybindings.json`, then contexts, sequences, menus and key spelling, each
  with its example. The docs check gains step markers (`NAME#N`) and file
  markers (`file:PATH`), so every block is still an Example or a file the
  Examples read. _(Decisions: D9)_

  Gate: a green local `make check`.
- **D15-KEYS** Keys are named in Ghostty's vocabulary. A key is a
  physical key (a W3C code value in snake case: `page_down`, `key_w`) or a
  character (`ctrl+w`, `?`), and the program decides which it sends.
  - **Reading.** Keys are read as Ghostty reads them. `StrictKeys` and
    `ShiftedCapitals` read more strictly.
  - **Aliases.** `<name>` is an alias from the schema or a document, which
    replaces the leader.
  - **HOTTY.** `ParseHotty` maps §10.4's names onto the new keys until HOTTY
    renames them.
  - **Docs.** The docs, the examples, the key table and the kubecom test
    follow; the test reads capitals as vim does. _(Decisions: D15)_

  Gate:
  - a green local `make check` and staticcheck;
  - 30 s of fuzzing for each parser;
  - the root builds against the pushed `myelinkey` commit with no replace.
- **PUBLIC** myelin is public, after the maintainer's review, and CI runs
  on `ubuntu-latest` from this push on. A problem now quotes keys as the
  user's file writes them, as kubecom asked (`unbind "X"`, not
  `shift+x`). kubecom's switch is green locally on myelin e5a8dea with
  myelinkey 0036c3f, and is its own to push. _(Decisions: D8)_

  Gate: a green local `make check`, then CI.
- **KEYSPEC** The key names are a spec: `myelinkey/SPEC.md`, version 0.1.
  - **Vectors:** 357 hand-written vectors in
    `myelinkey/conformance/keys.json` cover readings, strict reading,
    shifted capitals, splitting, sequences and display. myelinkey runs them
    under Go and TinyGo.
  - **Appendix A**, the physical keys, is generated and checked.
  - **Modifier keys:** a modifier tapped on its own is now a key (`shift`,
    `ctrl+shift`), so a double tap of Shift is `shift shift`. `Split`
    returns a `Kind`. _(Decisions: D16)_

  Gate:
  - a green local `make check`, staticcheck and 20 s of fuzzing for each
    parser;
  - the plx handover's tests;
  - the root builds against the pushed `myelinkey` commit with no replace;
  - then CI.
- **PERF** Benchmarks and the allocations they found.
  - **Changes:**
    - A query evaluates each distinct context once: the keymap numbers its
      contexts at build, and a pooled activation keeps their depths for the
      query.
    - `KeyFor` and `KeysFor` look only at the action's own bindings.
    - Menus list keys with one scratch map, and nest levels in one buffer.
    - `Feed` keeps the sequence on the stack unless a state keeps it.
  - **Results:** against the previous head, on a busy machine:

    | Operation | Before | After |
    |-----------|--------|-------|
    | KeyFor | 109 µs, 285 allocs | 0.6 µs, 4 |
    | Leader menu | 72 µs, 370 allocs | 28 µs, 60 |
    | Effective | 153 µs, 759 allocs | 62 µs, 23 |

    A prefix now allocates nothing.
  - **New:** `make bench` runs the benchmarks, and `TestAllocs` holds the
    allocation counts in the gate.
  - **No API change:** `KeyFor` returns the keymap's own binding, as
    `Match` does.
  - **Left:** CEL's errors for attributes off the prefix are most of what a
    match still allocates. Returning a shared error value from the
    activation would remove them. myelinkey's parsing allocates 2–8 times
    a name. Neither is started.

  Gate:
  - a green local `make check` and staticcheck;
  - the plx handover's tests;
  - then CI.
